# 미 육군, AI 기반 'Project Gatekeeper'로 상용 소프트웨어 군사 검증 프로세스 가속화 계획

## 핵심 요약

미 육군은 상용 소프트웨어의 군사 검증을 자동화하고 가속화하기 위한 'Project Gatekeeper'를 추진 중이다. 이 프로젝트는 기존 수개월이 걸리던 운영 권한 승인(ATO) 절차를 자동화하여 상용 벤더가 신속하게 코드를 제출하고 검증을 받을 수 있도록 한다. 초기 단계에서 OpenAI와 협력해 AI 모델을 활용한 검증을 도입할 예정이며, 차후 다른 공개 소스 및 상업용 모델로 확장할 계획이다. 이 플랫폼은 미 국방부 공통접근카드를 가진 벤더가 로그인할 수 있으며, 로그인.gov를 통한 접근 확대도 준비 중이다.

## 근거

- 프로젝트명: Project Gatekeeper
- 목적: 권한 승인(ATO) 프로세스 자동화 및 가속화, 코드 신속 검증
- 절차: 상용 벤더가 군 DevSecOps 플랫폼에 코드 제출 → 신속 검증 → IL5(Impact Level 5) 환경으로 이전
- 초기 협력: OpenAI와 협력, AI 모델 'Daybreak' 활용 예정
- 도입 시기: AI 모델 통합은 다음 분기 내 계획
- 접근성: 국방부 공통접근카드 보유 벤더가 로그인 가능, 로그인.gov 통한 범위 확대 예정
- 보안 방안: 벤더가 자체 API 키 사용, 코드 스캔 로그는 벤더만 확인 가능하도록 설계
- 향후 계획: 다른 오픈소스 및 상업 모델 제공자 추가 및 다양한 검증 방법 도입 검토
- 목표: 군과 산업 간 관계장벽 해소 및 신속한 제품 배포 지원
- 군 CIO Gabe Chiulli 발언 인용: AI 검증 절차에서 반복적 작업 최소화, 효율적·전략적 검증 도입 의지
- 상호 운영성: 타 군 CIO들과 '상호 인정(Reciprocity)' 체계 구축 협의 중

## 시사점 · 해석

원문 기반 해석: 미 육군이 AI를 활용해 복잡하고 시간이 오래 걸리는 군사 소프트웨어 운영 권한 승인 절차를 자동화하려는 시도는 상용 기술의 군사 적용 가속화를 목적으로 한다. 이는 OpenAI와의 협력과 단계적 AI 통합 계획에서 확인되며, 이를 통해 기존의 긴 검증 기간과 관계장벽을 극복하고자 하는 제한적이지만 구체적인 전략으로 해석된다.

## 핵심 요약

우크라이나군의 디지털 전쟁 성과는 AI 활용보다는 시스템과 데이터를 통합하는 강력한 권한 체계에 기인한다. 자동화와 AI는 일부 전투 임무에 제한적으로 적용되며, 높은 성능을 위한 양질의 통합 데이터 확보가 여전히 과제로 남아있다. 우크라이나의 DELTA 플랫폼은 하이퍼스케일 인프라 기반 API 중심 아키텍처로 다양한 사용자와 시스템을 연결하지만 통신과 주권 문제, 지연 문제가 존재한다. 강력한 지휘권과 전군 차원의 도입 확대가 디지털 전쟁 성과에 중요하며, 개발자와 사용자 간 긴밀한 협력 체계도 성공요인이다. 영국 디지털 타깃팅 웹(DTW)은 우크라이나 사례에서 API 모델의 확장성과 통합 필요성을 참고하되, 국내 호스팅 한계와 통신 취약성에 주의해야 한다.

## 근거

AI 및 자동화 활용 현황: 우크라이나군은 AI를 일부 영상 인식, 드론 항법 보조 등 좁은 분야에 적용하며, 자율 교전은 빈번하지 않음. Sky Sentinel 자율 교전 기능도 데이터 부족과 낮은 성능으로 수동 조작이 주류임. 통합 데이터 부족과 분산된 군 구조로 인해 고도 AI 모델 적용에 한계 있음. DELTA 플랫폼: 하이퍼스케일 인프라(국외 소재)와 현장 호스팅을 병행하며 API 기반 데이터 송수신 체계 구축. 월 2~3회 업데이트로 빠른 반복 가능. Starlink 통신 의존성과 호스팅 주권 문제 존재. DELTA 적용 확대는 우크라이나 전 총사령관 Oleksandr Syrskyi의 강력한 명령과 전군 참여 유도로 성공. DTW는 DELTA와 비슷한 API 모델 사용하지만 영국 SECRET 클라우드는 하이퍼스케일 성능 미달로 주의 필요, 연결성과 상호운용성 확대 위해 노드 비종속성 필요. 우크라이나는 위험 감수하며 속도와 기능 확대 위해 장기간 시험 대신 실전 배치를 통한 반복 개선 추진. 개발자-사용자 긴밀 협력 체계 운영, 산업계는 비협조 업체 배제. NATO는 DELTA API 라이브러리 방식 일부 모방 고려 가능. 디지털 전쟁 성공은 AI 기술 자체보다 시장성과 강력한 도입 권한, 체계적 데이터 통합, 운영자 간 협력에 달려있음.

## 시사점 · 해석

원문 기반 해석: 우크라이나 사례는 AI 자체의 혁신보다 데이터와 시스템 통합, 그리고 강력한 중앙 권한의 중요성을 강조한다. 이는 DTW 같은 미래 디지털 전쟁 체계 설계에서 단순 AI 도입보다 통신 안정성, 데이터 주권, 유연한 통합 전략, 그리고 전군 차원 도입 유도를 핵심 과제로 보도록 한다. 영국과 NATO가 우크라이나 경험을 토대로 AI 기능 독립 치중에서 벗어나 운영 환경과 조직 문화, 인프라 통합의 실체적 문제 해결에 집중할 필요가 있음을 시사한다.
